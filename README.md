# Andria Gvaramia

Computer science student and developer. I build AI agents and computer vision projects in Python, and iOS apps in Swift.

## Projects

- [hotel-voice-agent-langgraph](https://github.com/andriagv/hotel-voice-agent-langgraph) – Georgian-language hotel voice assistant built on LangGraph and Claude: PMS tool calls, answer self-checking, human-in-the-loop order confirmation and escalation to staff (Python).
- [HWorkestrator](https://github.com/andriagv/HWorkestrator) – Telegram bot that solves university assignments with Claude and uploads the result to Moodle or Google Drive only after you approve each step (Python).
- [ESP32_cam_TeachableMachine](https://github.com/andriagv/ESP32_cam_TeachableMachine) – ESP32-CAM web interface that runs Teachable Machine image and pose models on the live camera stream (C++).
- [NumericalProgramingFinalProject](https://github.com/andriagv/NumericalProgramingFinalProject) – simulates an illuminated drone show with numerical methods, including formation keeping and shape transitions (Python).
- [virtualPainter](https://github.com/andriagv/virtualPainter) – draw on screen with your hand only, using OpenCV and MediaPipe hand tracking (Python).
