# Andria Gvaramia

iOS developer and mathematics student. I mostly write Swift, plus Python for numerical work and computer vision experiments.

## Projects

- [NumericalProgramingFinalProject](https://github.com/andriagv/NumericalProgramingFinalProject) – simulates an illuminated drone show with numerical methods (Python).
- [virtualPainter](https://github.com/andriagv/virtualPainter) – draw on screen with your hand only, using OpenCV and MediaPipe hand tracking (Python).
- [SaveBiteKutaisi](https://github.com/andriagv/SaveBiteKutaisi) – iOS app for reserving discounted leftover food from cafés and bakeries in Kutaisi, with QR pickup and food-waste stats (Swift).
- [ESP32_cam_TeachableMachine](https://github.com/andriagv/ESP32_cam_TeachableMachine) – ESP32-CAM web interface that runs Teachable Machine image and pose models on the live camera stream (C++).
- [NetworkPackage](https://github.com/andriagv/NetworkPackage) – minimal `URLSession` wrapper for fetching JSON with typed errors (Swift).

## Tools

Swift, Python (OpenCV, MediaPipe), C++ for Arduino/ESP32, Firebase, Git.
